FLUJO DE EJECUCIÓN
================================================================================

1. _SETUP (5 requests)
   │
   ├─ 01. Register Artista User
   │  └─ Genera email único con timestamp
   │  └─ Obtiene JWT token del artista
   │
   ├─ 02. Register Fan/Proveedor User
   │  └─ Genera email único con timestamp
   │  └─ Obtiene JWT token del fan
   │
   ├─ 03. Extract Artista UserId from Token
   │  └─ Decodifica JWT y extrae UserId
   │
   ├─ 04. Create Necesidad
   │  └─ Crea contexto para conversación
   │  └─ Guarda necesidadId
   │
   └─ 05. Create Propuesta
      └─ Establece relación entre artista y fan
      └─ Guarda propuestaId

2. CONVERSACIONES - CRUD LIFECYCLE (4 requests)
   │
   ├─ 01. POST Create Conversacion
   │  └─ Crea conversación entre artista y fan
   │  └─ Guarda conversacionId
   │
   ├─ 02. GET All Conversaciones
   │  └─ Listar conversaciones con paginación
   │  └─ Verifica que conversación creada aparece
   │
   ├─ 03. GET Conversacion By Id
   │  └─ Obtiene mensajes de conversación
   │  └─ Verifica acceso de participante
   │
   └─ 04. GET No Leidos Count
      └─ Endpoint ligero para badge del navbar
      └─ Retorna conteo total

3. MENSAJES - CRUD LIFECYCLE (5 requests)
   │
   ├─ 01. POST Send Mensaje (sin adjunto)
   │  └─ Envía mensaje del artista al fan
   │  └─ Guarda mensajeId
   │
   ├─ 02. POST Send Mensaje with URL
   │  └─ Envía mensaje del fan con URL adjunta
   │  └─ Guarda mensajeId2
   │
   ├─ 03. GET Mensajes from Conversacion
   │  └─ Obtiene lista de mensajes paginada
   │  └─ Verifica que ambos mensajes aparecen
   │
   ├─ 04. PATCH Marcar Leidos
   │  └─ Marca mensajes del artista como leidos
   │  └─ Retorna conteo de marcados
   │
   └─ 05. Verify Total No Leidos Decreased
      └─ Verifica que conteo de no leidos se actualizó

4. VALIDACIONES (6 requests)
   │
   ├─ Asunto vacio / too long
   ├─ Destinatario faltante
   ├─ Contenido mensaje vacio / too long
   └─ URL adjunta inválida

5. AUTENTICACIÓN (3 requests)
   │
   ├─ Sin token (401)
   ├─ Token inválido (401)
   └─ No es participante (403)

6. NOT FOUND (3 requests)
   │
   ├─ Conversación no existe
   ├─ Enviar mensaje a conversación inexistente
   └─ Marcar leidos en conversación inexistente

7. BUSINESS RULES (1 request)
   │
   └─ Conversación duplicada (4015)

8. PAGINACIÓN (2 requests)
   │
   ├─ Conversaciones respeta max 50

TROUBLESHOOTING RÁPIDO
================================================================================

Problema: "401 Unauthorized"
Solución: Verificar que backend está running y JWT key es correcta

Problema: "404 Not Found" en endpoints
Solución: Verificar que módulo Crowdsourcing tiene migraciones aplicadas

Problema: "Email duplicado"
Solución: Ejecutar nuevamente (el _Setup genera email con timestamp)

Problema: "Connection timeout"
Solución: Aumentar timeout en Newman: --timeout-request 10000

Problema: Newman no encontrado
Solución: npm install -g newman newman-reporter-htmlextra

Para más detalles, consultar:
  → README-POSTMAN.md (sección Depuración)
  → COLLECTION-SUMMARY.md (sección Limitaciones)
